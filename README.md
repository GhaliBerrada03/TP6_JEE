# 📦 Demo Spring Boot Project

## 📖 Description
Application Spring Boot simple utilisant :
- Spring Data JPA
- Validation (Hibernate Validator)
- Architecture en couches

Une entité principale : **User**

---

## 🗂️ Structure
- ma.example.demo : package principal
- domaine : entités (User)
- resources :
  - templates : vues HTML
  - static : fichiers CSS
  - application.properties : configuration

---

## ⚙️ Technologies
- Java
- Spring Boot
- Maven
- JPA (Hibernate)
